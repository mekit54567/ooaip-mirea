| Папка | Работа |
|---|---|
| [`pr1`](pr1) | Практическая работа № 1 — синтаксис и управляющие конструкции Java, классы и UML (Author), абстрактные классы и интерфейсы (Shape, Movable), перечисления, дополнительные задания |

| [`pr3`](pr3) | Практическая работа № 3 — GUI на Swing, статические члены и массивы объектов, вложенные и внутренние классы, обработка событий |
| [`pr4`](pr4) | Практическая работа № 4 — рекурсия, исключения |
| [`reports`](reports) | Отчёты по работам (.docx) |

В папках `compile-errors` лежат примеры из заданий, которые специально не компилируются (разбор ошибок есть в отчётах), поэтому они исключены из исходников модуля.

## Запуск

Открыть корневую папку в IntelliJ IDEA (File → Open), указать SDK 17 и запустить нужный класс с методом `main`.

Из командной строки, например для ПР1:

```
cd pr1/src
javac -encoding UTF-8 -d ../../out/pr1 part1/*.java
java -cp ../../out/pr1 part1.ArraySum
```
